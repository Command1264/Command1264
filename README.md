- Python：資料處理、工具開發、CLI/headless workflow、pytest
- AI / Computer Vision：YOLO、OpenCV、Ultralytics YOLO、模型訓練與推論整合
- Backend / Integration：Flask、HTTP API、JSON request/response、batch inference、worker pipeline、logging
- Agentic AI Workflow：需求拆解、可重現診斷、自動化驗證、人工情境測試與最終驗收
- Desktop Tools：PySide6、Windows tray application、PyInstaller、Nuitka
- .NET / Windows：C#、.NET 10、WPF、MVVM、Windows GSMTC、顯式狀態機
- JVM / Build：Kotlin、Java、Gradle、ShadowJar、Bukkit API、Spigot／Paper、CSV/Excel 輸出
